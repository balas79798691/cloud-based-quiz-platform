# ☁️ CloudQuiz

A simple cloud-based quiz platform built with React, Node.js, Express, and PostgreSQL.

## Features
- Student quiz interface
- Multiple-choice questions
- Score calculation
- Quiz result storage
- REST API
- PostgreSQL database
- Clean responsive UI
- Docker-ready database

## Stack
Frontend: React + Vite
Backend: Node.js + Express
Database: PostgreSQL

## Run

### Database
```bash
docker compose up -d db
```

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Frontend: http://localhost:5173
Backend: http://localhost:5000
